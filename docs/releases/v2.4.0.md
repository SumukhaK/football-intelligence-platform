# Football Intelligence Platform — Release v2.4.0

**Version:** v2.4.0
**Release Date:** 2026-10-15
**Previous release:** [v2.3.0](v2.3.0.md)

A minor release from the first use of staging on a phone: the assistant now chats instead of reporting, and it no longer shows users its internal sources. The API reports version 2.4.0. The full list is in the [changelog](../../CHANGELOG.md#240--2026-10-15).

---

## Changed

- **A conversational assistant** ([#122](https://github.com/SumukhaK/football-intelligence-platform/pull/122)). It gives the answer first in plain words, adds one line of context from the data, keeps to a few sentences and replies naturally to small talk. The grounding rules are unchanged, and the evals pass on Workers AI: abstention 20/20, grounding 11/11 and season 7/7.
- **Sources logged, not shown** ([#123](https://github.com/SumukhaK/football-intelligence-platform/pull/123), ADR 029). The model still cites, but the server strips the `[source: ...]` markers and returns an empty `sources` list. It records the retrieved documents and the citations in the `assistant.answer` log line. The app hides the sources card and the confidence when there are no sources.

## Fixed

- The grounding eval no longer counts "Ligue 1" as an invented number (#122).

## Upgrading
