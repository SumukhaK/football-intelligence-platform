# Football Intelligence Platform — Release v2.5.0

**Version:** v2.5.0
**Release Date:** 2026-10-15
**Previous release:** [v2.4.0](v2.4.0.md)

A minor release: the assistant remembers the conversation. The app sends the last 4 exchanges with each question, and the server signs its own answers so a modified app can't forge them. Nothing is stored on the server. The API reports version 2.5.0. The full list is in the [changelog](../../CHANGELOG.md#250--2026-10-15).

---

## Added

- **Chat memory** ([#128](https://github.com/SumukhaK/football-intelligence-platform/pull/128), [#130](https://github.com/SumukhaK/football-intelligence-platform/pull/130), ADR 030):
  - `POST /v2/assistant/chat` takes an optional `conversation_id` and `history` and signs every answer with `HISTORY_KEY`.
  - History with an unsigned or edited answer is ignored, and long history is trimmed to 1,200 tokens.
  - Llama Guard reads the user's earlier questions with the new one.
  - The app has a New chat button and starts afresh after 30 minutes idle.
  - Request bodies may be 24 KB.
- **Conversation eval** ([#129](https://github.com/SumukhaK/football-intelligence-platform/pull/129)). `evaluation.assistant_conversation` runs eight scripted chats covering follow-ups, a topic switch, a forged answer, injection in the history and a split harmful request.
- **Design docs** ([#127](https://github.com/SumukhaK/football-intelligence-platform/pull/127)). ADR 030, the [chat memory plan](../plans/chat-memory-plan.md) with its architecture diagram, and hosting tracker step 3c.

## Fixed

- **Worked-out numbers in follow-ups** (#129). A follow-up answer with a number no tool returned this turn is asked again once. The model had been working out the draw chance from its earlier answer, sometimes wrongly.
- **Wrong club names** (#129). Tools find the league from the two team names when the model gives none. The prompt keeps the tools' team names, so "Ath Madrid" is no longer written as "Athletic Madrid".
- **App bar and result screen** ([#126](https://github.com/SumukhaK/football-intelligence-platform/pull/126)). Every screen shares one green top bar. New prediction no longer flashes an error while the result screen closes.

The staging app is shared directly with invited users, not attached here.

## Upgrading

Install the new app build. A hosted backend needs a `HISTORY_KEY` secret: the server won't start on Cloud Run with the assistant on and the development key. Older app builds send no history and keep working, one question at a time.
