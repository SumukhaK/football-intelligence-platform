# Football Intelligence Platform — Release v2.0.1

**Version:** v2.0.1
**Release Date:** 2026-09-29
**Previous release:** [v2.0.0](v2.0.0.md)

A patch release: one app fix and the demo video. The API is unchanged and
still reports version 2.0.0.

---

## Fixed

- **Offline mode falls back within seconds** ([#54](https://github.com/SumukhaK/football-intelligence-platform/pull/54)).
  With the server unreachable, the app used to wait about 50 seconds before
  showing saved data under the offline banner. It used the 30-second request
  timeout for connecting too, and Android retried once. Connecting now gives
  up after 5 seconds, while a connected request still gets 30. On the
  emulator the banner now appears after about 10 seconds.

## Added

- **Demo video** ([#53](https://github.com/SumukhaK/football-intelligence-platform/pull/53)).
  A 3-minute narrated walk-through with English subtitles, linked from the
  top of the README. Scenes and capture notes are in
  [docs/showcase/demo-video](../showcase/demo-video/README.md).
- **Dated accuracy check** ([#52](https://github.com/SumukhaK/football-intelligence-platform/pull/52)).
  The README's 2026/27 section now says when it was measured.
