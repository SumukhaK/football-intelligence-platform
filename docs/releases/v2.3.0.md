# Football Intelligence Platform — Release v2.3.0

**Version:** v2.3.0
**Release Date:** 2026-10-15
**Previous release:** [v2.2.0](v2.2.0.md)

A minor release: the staging backend is live on Cloud Run, and the staging app reports crashes. The API reports version 2.3.0. The full list is in the [changelog](../../CHANGELOG.md#230--2026-10-15).

---

## Added

- **Crash reports from the staging app** ([#116](https://github.com/SumukhaK/football-intelligence-platform/pull/116), ADR 028). The `staging` build sends crashes to Firebase Crashlytics, but only after the user accepts the notice. The `local` build has no Firebase code. The Firebase config stays out of Git, and a build without it still works.

## Changed

- **Consent notice version 2** (#116). It now says crash reports go to Google and that answers come from a model hosted by Cloudflare, so every user is asked to accept it again.
- **Hosting tracker** ([#117](https://github.com/SumukhaK/football-intelligence-platform/pull/117)). It records the staging deploy of 14 October 2026: the image is pushed by digest, the service is live, and a cold start takes 19 s from instance start to ready.

## Fixed

- **Refresh alert window** ([#118](https://github.com/SumukhaK/football-intelligence-platform/pull/118)). Cloud Monitoring rejected the 26-hour lookback, so it is now 25 hours.
- **Monitoring scripts on Windows** ([#119](https://github.com/SumukhaK/football-intelligence-platform/pull/119)). The scripts now strip the carriage return gcloud adds on Windows, so re-running `apply.sh` replaces each alert policy.
