# Football Intelligence Platform — Release v2.1.0

**Version:** v2.1.0
**Release Date:** 2026-09-29
**Previous release:** [v2.0.1](v2.0.1.md)

A minor release: the app gets its own identity, and the project gets a safer release process. The API is unchanged and still reports version 2.0.0.

---

## Added

- **App icon** ([#56](https://github.com/SumukhaK/football-intelligence-platform/pull/56)). The Tactics Board adaptive icon: a pitch with the predicted run to the ball. It has a monochrome layer, so Android 13+ can tint it to the wallpaper.
- **Kick-off launch screen** (#56). Brand green with the Kick-off ring. On Android 12+ the home, draw and away arcs fill in as the app opens; on Android 8 to 11 the finished ring shows as a still image. Uses AndroidX `core-splashscreen` ([ADR 016](../adr/016-app-icon-and-kickoff-launch-screen.md)).
- **Kick-off loading animation** (#56). The same ring animation replaces every loading spinner: full-screen loading, pull to refresh, the backend status card, the likely-scores section and the assistant's "sending" state.

## Changed

- **Documentation brought up to date** ([#57](https://github.com/SumukhaK/football-intelligence-platform/pull/57), [#58](https://github.com/SumukhaK/football-intelligence-platform/pull/58)). Every markdown file was checked against the code. The showcase set, setup guide, CLI reference, troubleshooting guide, changelog, repository structure and stage demos now describe v2. ADRs note what later ADRs superseded. The README's "Lessons Learned" section was removed.
- **Branch flow** ([#59](https://github.com/SumukhaK/football-intelligence-platform/pull/59)). Work now merges into `develop`; `main` only receives release pull requests from `develop` and hotfixes, and every merge into `main` is tagged. CI runs on pull requests into both branches, and both are protected on GitHub.

## Downloads

- `football-intelligence-v2.1.0-debug.apk`: debug build, installs directly.
- `football-intelligence-v2.1.0-debug.aab`: the same build as an Android App Bundle.

The debug build calls the backend at `http://10.0.2.2:8000/v2`, the host machine as seen from the Android emulator. To use a physical device, change `baseUrl` in `NetworkConfig.kt` to your computer's LAN address and rebuild.

## Upgrading

Install the new app build. The backend needs no change.
