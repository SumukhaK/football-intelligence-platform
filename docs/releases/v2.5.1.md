# Football Intelligence Platform — Release v2.5.1

**Version:** v2.5.1
**Release Date:** 2026-10-15
**Previous release:** [v2.5.0](v2.5.0.md)

A patch release that records the staging deploy. The code is v2.5.0's; only the version number, the README, the website and the hosting tracker change.

---

## Changed

- **Staging runs v2.5.x on Google Cloud Run.** The image is built with Cloud Build and uses a new `history-key` secret for chat memory. Checked through the public URL:
  - sign-in and consent
  - a prediction
  - a signed follow-up ("and the draw?" answered with 24.7%)
  - a forged history, which was ignored
- **README and website.** Both say an invite-only staging service is live, and the website describes chat memory and the safety check.
