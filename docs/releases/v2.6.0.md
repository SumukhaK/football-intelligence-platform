# Football Intelligence Platform — Release v2.6.0

**Version:** v2.6.0
**Release Date:** 2026-10-17
**Previous release:** [v2.5.1](v2.5.1.md)

A minor release built from the first days of the staging beta. It fixes what friends ran into (cold-start sign-ins, confusing invite errors, an assistant that ignored the saved team), makes invite codes easy to type, saves question text only for users who opted in, and gives the app a round of UI polish. The prediction model now has a public name, Drishti. The API reports version 2.6.0. The full list is in the [changelog](../../CHANGELOG.md#260--2026-10-17).

---

## Added

- **The assistant knows your favourite team** ([#136](https://github.com/SumukhaK/football-intelligence-platform/pull/136), ADR 031). The app sends the saved team with each question, so "where will we finish?" is answered for that team. The conversation eval gains a case for it.
- **Invite codes that are easy to type** ([#147](https://github.com/SumukhaK/football-intelligence-platform/pull/147)). Codes look like `K7QM-3XWD`, with no look-alike characters, and redeem in any case, with or without spaces and dashes. Codes already sent keep working.
- **Question text for users who opted in** ([#148](https://github.com/SumukhaK/football-intelligence-platform/pull/148), ADR 034). Each question is saved in Firestore with its outcome, model and conversation, not the answer, and a TTL policy deletes it after 90 days. A failed save never fails the chat.
- **The user reference on every assistant turn** ([#146](https://github.com/SumukhaK/football-intelligence-platform/pull/146)). `http.request`, the assistant events and `guardrail.event` carry the hashed `user_ref`, never the email. Telemetry contract 1.1.0.
- **A public model name** ([#144](https://github.com/SumukhaK/football-intelligence-platform/pull/144), ADR 033). `GET /model` returns `model_name` ("Drishti"); `model_version` stays the technical id.

## Changed

- **Clearer picks** ([#139](https://github.com/SumukhaK/football-intelligence-platform/pull/139), [#143](https://github.com/SumukhaK/football-intelligence-platform/pull/143)). One win/draw/loss bar with a crest at each end, a pick that names the team, a "Your team" tint on Fixtures, two starter questions in the assistant, and a Swap home and away button. The "Draw possible" label is gone from the app (ADR 011 update).
- **About screen** ([#141](https://github.com/SumukhaK/football-intelligence-platform/pull/141)). It scrolls, shows the real app version and has short cards on how the app works, its data and its stack.
- **More room in the assistant chat** ([#149](https://github.com/SumukhaK/football-intelligence-platform/pull/149)). No back arrow, and the bottom bar hides while the keyboard is open.

## Fixed

- **Cold starts** ([#135](https://github.com/SumukhaK/football-intelligence-platform/pull/135), [#142](https://github.com/SumukhaK/football-intelligence-platform/pull/142)). The app wakes the server when it opens, sign-in and invite redemption wait up to 60 seconds with "The server is waking up", and Cloud Run's own 429 is retried instead of reading as a lockout.
- **Invite errors** ([#140](https://github.com/SumukhaK/football-intelligence-platform/pull/140), ADR 032). The right code redeemed again says the account is set up (409), and an expired one says so (410).
- **Dark mode** ([#137](https://github.com/SumukhaK/football-intelligence-platform/pull/137)). A deep green top bar, an outlined settings gear, and gold and red for top four and relegation.

## Upgrading

A hosted deployment needs a one-off Firestore TTL policy on `expires_at` for the questions collection (hosting tracker 3a); until it is set, saved questions are kept. Older app builds keep working; they just don't send the favourite team.
