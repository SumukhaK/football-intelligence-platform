# Football Intelligence Platform — Release v2.0.0

**Version:** v2.0.0
**Release Date:** 2026-09-29
**Previous release:** [v1.0.0](v1.0.0.md) (2026-07-01)

---

## Why a Major Version

v2.0.0 changes the API contract and replaces the model. The API now serves five
leagues, adds `competition` and `draw_possible` fields and new endpoints, and
answers with a model retrained on 26 seasons. Clients built for v1.0.0 keep
working because `/v1` and the unversioned paths keep the old contract and the
old model (ADR 014). The app moves to `/v2`.

---

## Highlights

- **Five leagues.** Premier League, Bundesliga, La Liga, Serie A and Ligue 1, 2000/01 to 2025/26: 46,709 matches (ADR 005, ADR 012).
- **Retrained model** `20260928_123224`, with a season-based split and walk-forward tuning (ADR 007). On the 2023/24 test season it scores 52.5% accuracy and log loss 0.976, against 55.0% and 0.955 for bookmakers. On 2026/27 matches played so far it is 52.4% accurate, against 51.6% for bookmakers' favourites ([report](../reports/in-season-2026-27.md)).
- **Server-side features.** Clients send two team names; the server builds all 42 features from match history (ADR 008).
- **Plain-language explanations.** Every SHAP contribution has a fan-friendly label, such as "Arsenal win rate at home · 68%".
- **Draw tag.** Predictions with a draw probability of at least 0.28 are tagged "draw possible". The tag never changes the pick (ADR 011).
- **Goals model.** A Dixon-Coles model per league gives the likely scores, expected goals and goal markets through `POST /v2/insights` (ADR 009).
- **Upcoming fixtures.** `GET /v2/fixtures` lists each league's schedule, taken from openfootball (ADR 015).
- **Daily refresh.** The server downloads new results and fixtures every morning and swaps them in without a restart (ADR 013).
- **Versioned API and rate limit.** `/v1` is frozen and `/v2` is current. Each client is limited to 120 requests a minute (ADR 014).
- **App.** The app opens on fixtures by date, with one tab per league. A bottom bar leads to Fixtures, Predict, Assistant and Settings. Predictions start with a league picker and show likely scores. Every answer is saved, so the app works offline with a banner, and a downward pull refreshes the data. Errors are explained in plain language.

## API Changes

| Change | v1 (`/v1`, unversioned) | v2 (`/v2`) |
|---|---|---|
| Model | `20260630_132617`, Premier League | `20260928_123224`, five leagues |
| `competition` request field | Premier League only | Any served league |
| `competition`, `draw_possible` in responses | Absent | Present |
| Explanation `display_name`, `display_value` | Absent | Present |
| `GET /competitions`, `GET /fixtures`, `POST /insights` | Not available | Available |
| Rate limit (429 with `Retry-After`) | Applies | Applies |

Full contract: [docs/api.md](../api.md).

## Upgrading

- **Backend:** copy any new settings from `ai/.env.example`: `V1_MODEL_PATH`,
  `V1_MODEL_VERSION`, `FIXTURES_DIR` and `RATE_LIMIT_PER_MINUTE`. The defaults
  work as they are. The v1 model must be at
  `ai/models/runs/20260630_132617/model.joblib`; without it, `/v1` answers 503.
- **Fixtures:** the server downloads them at startup when none exist. Run
  `uv run python -m scripts.refresh_fixtures --confirm` to fetch them by hand.
- **Clients:** move to `/v2` to get the five leagues and the current model.
