Recommendation

Icon 2 with splash S2, plus S3 in dark mode

  • Icon 2, the probability ring, is the only concept that shows what the app does: three outcomes around a ball. It stays recognisable as a flat monochrome themed icon because the gaps between the arcs carry the shape.
  • S2 and S3 follow the app's light and dark themes, so launch flows straight into the first screen without a colour flash.
  • S4's animation can be added later as a small extra, using the same icon.
